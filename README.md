## 核心学术贡献与理论体系

本研究在传染病传播与监测双层随机模型下，破除了公卫领域“病例监测规模越多越好”的盲目直觉，严格回答了**“监测规模在何处放缓，放缓由哪些随机性来源决定，以及资源应如何配置”**的根本问题：

1. **确立估计目标的理论分水岭（命题 1 与命题 2）**：
   - **当期瞬态再生数 $R_t$（目标Ⅰ）**：估计量 $\widehat{R}_t = \frac{C_t}{\rho n}$ 在任意有限样本 $n$ 下精确达到 Cramér–Rao 下界，属于 UMVUE，方差随规模单调趋零，**无不可约下限**；
   - **跨期平均水平 $\bar{R}$（目标Ⅱ）**：方差为 $V(m) = v_R + \frac{A}{m}$，单期推断留存不可消除的外生宏观**环境方差底板 $v_R$**。
2. **定义特征方差交叉点（定义 1）**：
   - 导出抽样方差与环境方差各占 50% 的平衡刻度 $m_\times = \frac{A}{v_R}$；
   - 证明曲线上无跳跃折点，方差关于规模严格凸；当规模达到 $m_\times$ 时，继续翻倍（$m \to 2m$）只能带来不到 25% 的方差缩减收益。
3. **界定监测杠杆非对称性（命题 3）**：
   - 提高报告率 $\rho \to 1$ 存在理论饱和下限，无法消除超传播个体异质性；唯有扩大实际感染人群基数 $n \to \infty$ 才能使微观抽样方差归零。
4. **多期运筹设计与抽样同构（命题 4 与推论 1）**：
   - 给出 AR(1) 弱平稳自相关下一阶自回归部分和方差的精确双重级数求和闭式，指明有限期数下常用近似 $T_{\mathrm{eff}}$ 的高估偏差；
   - 引入固定期成本 $c_0$ 与边际成本 $c_1$，证明最优配置问题在数学结构上**同构于经典两阶段抽样费用最优分配（Cochran, 1977）**，解出闭式驻点：
     $$m^* = \sqrt{\frac{c_0}{c_1} m_\times}$$
5. **离散小样本下的精确增长检验（命题 5）**：
   - 证明负二项分布族关于 $R_t$ 具有严格单调似然比（MLRP），确立临界门槛规则 $C_t \ge c_\alpha$ 是控制第 I 类错误水平的一致最大功效（UMP）检验；
   - 揭示常用正态近似 Wald 检验在小规模（$m < 40$）且极重尾（$k \le 0.35$）时系统性过检（实际水平升至 8%–10%），指明使用精确检验的必要性。

## 关键实证发现与量化证据

基于全美 CDC NHSN 51 个地理辖区 2020 年 10 月至 2026 年 9 月共 16,218 个州周住院数据，研究取得了如下量化结果：

* **形态验证**：流行初期单步预测相对均方误差随规模呈 $a + \frac{b}{D_t}$ 形式递减并趋于常数底板，经验交叉点测定为 $m_\times = 22.6$ 例/周（95% 聚类区间 $[13.7, 33.7]$），与理论情景参数区间 $[21.3, 49.2]$ 高度吻合；
* **分母噪声与时滞偏差解析（式 15）**：
  - 严格通过 Delta 方法展开证明分母 $D_t$ 作为随机计数会带来二项报告噪声，导致斜率 $b$ 向上放大约 3 倍（式 15 对不同滞后权重的相对预测与实测值 1.40 及 0.86 完全一致）；
  - 证明截距 $a$ 随回溯滞后单调上升，源于宏观环境时间自相关引发的条件偏差，因此经验交叉点应定位为系统量级参考而非点位结构参数；
* **达峰期机制定性反证**：
  - 证实达峰期误差居高不下（88.9% 损失）源于疫情见顶转折引发的“常数基准漂移（跨期平稳假设失效）”；
  - 剥离均值漂移后，纯条件方差关于规模的斜率依然显著为正（$b=7.9272$），同一样本联合回归交互项区间 $[-2.33, 0.59]$ 包含零，**推翻了“达峰期规模失效”的传统推断**；
* **填报制度跳变自然实验**：
  - 发现强制转自愿填报后标准差放大 192%，但四分位距（IQR）和中位绝对偏差（MAD）基本平稳，揭示出噪声源于少数医院断续填报造成的跳变，而非均匀漏报；
* **外部跨病种与前瞻集成检验**：
  - 在 CDC FluSight 前瞻多模型集成预测（$m_\times=60.3$）与欧洲 11 国早期 COVID-19 序列（$m_\times=124.7$ 例/天）中，规模项系数 $b$ 全部显著为正，且 FluSight 多模型集成成功将达峰期均值偏差压缩至 15.5%。

## 运行与编译环境

### 1. 软件依赖
- **Python 3.10+**：`numpy`, `scipy`, `pandas`, `matplotlib`, `sympy`
- **LaTeX 编译器**：推荐使用 **XeLaTeX**（搭载 `ctex` 宏包）或 **Tectonic**

### 2. 一键编译小论文（`paper/`）
```bash
cd paper
bash compile.sh
# 或直接运行:
# xelatex main.tex && bibtex main && xelatex main.tex && xelatex main.tex
```

### 3. 一键编译硕士大论文（`thesis/`）
```bash
cd thesis
bash compile.sh
# 编译完成后生成 91 页完整的 学位论文.pdf
```

### 4. 运行数学核验套件（`code_and_data/`）
```bash
cd code_and_data/code/checks
python c01_prop1_sympy.py      # 命题 1 符号证明与 CRLB 验证
python c03_prop2_mx_prop3.py   # 命题 2 & 3 方差底板与杠杆验证
python c04_prop4_ar1.py        # 命题 4 AR(1) 双重级数闭式验证
python c05_cor1.py             # 推论 1 成本最优规模凹凸性与闭式解验证
python c06_prop5.py            # 命题 5 单调似然比 UMP 与过检仿真
python c11_fgls_bootstrap.py   # 实证 FGLS 与州聚类 Bootstrap 检验
python c12_eq15_derivation.py  # 式 15 随机分母 Delta 展开与权重敏感性推导
```
