## 第 8 条：附录 A.8 补写式 (15) 的推导

意见要点：附录 A.8 只给出了式 (15) 的结论，建议补一段推导。原建议的步骤如下：

1. 分母 D_t 的条件均值为 ρΛ，条件方差为 ρ(1−ρ)Σw_s²I。
2. 取 I≈Λ，得 Var(D/ρΛ)≈(1−ρ)Σw²/m。
3. 对 G=C/D 作一阶 delta 展开，得到附加项 E(R²)·Var(δ)，并取 E(R²)=R̄²+v_R。
4. 与 A/m 合并后同除以 R̄²，得到斜率 b。

判断：部分成立。核验分三层：用 sympy 做符号推导，对固定的 m 逐点枚举二项分布，再做蒙特卡洛。脚本为 `theory/checks/c12_eq15_derivation.py`，结果写在 `theory/checks/results/c12_eq15_derivation.json`（逐项记录）和 `c12_eq15_derivation_detail.json`（全部数值）中，两份文件都已收进下载包的 `results/` 目录。

原建议中正确的部分：

- 分母的条件均值 ρΣw_sI_{t+1−s} 和条件方差 ρ(1−ρ)Σw_s²I_{t+1−s} 都正确（检查 12.1）。
- 只保留一阶 δ 项时，Var(G) 的 1/m 项正好是 A+(R̄²+v_R)(1−ρ)Σw²，E(R²)·Var(δ) 这一附加项也写对了（检查 12.2）。
- 最终得到的系数与正文式 (15) 一致。

原建议需要修正或补充的五处：

1. 二阶项与 1/m 同阶，不能略去。δ² 的期望为 c/m，其中 c=(1−ρ)Σw²，与要保留的项同阶。保留到 1/m 后，Var(G|m) 的系数变为 A+(R̄²+3v_R)c，比一阶结果多出 2v_R·c；同时条件均值抬高为 R̄(1+c/m)（检查 12.3）。
2. 两种归一化的差别要写明。“同除以 R̄²”要理解为除以条件均值的平方 E(G|m)²≈R̄²(1+c/m)，这时 1/m 的系数恰好等于式 (15)。也就是说，式 (15) 是条件变异系数平方 CV²(G|m) 的展开系数（检查 12.5）。若按正文损失 L_t=[(G_t−R̄)/R̄]² 以固定的 R̄ 归一化，系数为 [A+(1−ρ)(R̄²+3v_R)Σw²]/R̄²（检查 12.4）。在 6.3 节的情景参数下，主规格因此多出 0.021，约为式 (15) 的 1.8%。正文略去这一项，附录中已写明。
3. 平稳近似 I≈Λ 是必要条件，还要求 D 的滞后权重与 Λ 的权重相同且 Σw_s=1。规模以周增长比 r 变化时，Σw² 应换成 Σw_s²I_{t+1−s}/Λ_{t+1}。主规格在 r=1 时为 0.495，r=1.67 时为 0.555（多 12%），r=0.8 时为 0.461（检查 12.6）。
4. 推导要求当期报告与往期报告的抽样条件独立，展开中才没有交叉项。若报告比例存在跨周的共同冲击，X 与 δ 相关，会多出一项。模拟中 X 与 δ 的样本相关系数约为 0.003。
5. m 的含义要与正文对齐。推导中的 m=ρΛ_{t+1} 是在给定真实感染史 H_t 的条件下取的；正文定义的 m=ρE(Λ_{t+1}|F_t) 多一层报告噪声。实证拟合又以 D_t 代替 m 作回归元，属于含噪回归元问题。此外，展开只在 m 足够大时可靠。

实际改动：`sections/appendix.tex` 第 124 行起的 A.8。

- 在“式 (11) 是两边同除以 R̄D_t 的代数恒等式。”之后新增三段（第 139–156 行）和四个不编号的公式，正文的公式编号不受影响：
