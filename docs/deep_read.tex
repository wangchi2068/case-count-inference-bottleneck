\section{导读前言：应用统计研究生的“论文通透心法”}

阅读或答辩这篇论文时，首先要建立一个宏观全局认知：\textbf{本文是一篇高度典范的应用统计学顶刊风格论文}。它的行文与论证结构高度精密，由四根核心支柱环环相扣而成：


\begin{enumerate}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{微观概率论支柱}：从经典生灭分支过程（Galton–Watson 过程）出发，引入生物学超传播机制（Gamma 混合泊松分布，即负二项分布）与宏观观测不完全性（二项报告抽样过程），建立了双层随机生成机制；
\item \textbf{渐近统计推断支柱}：利用概率母函数（PGF）复合律证明了分布族闭包，计算得分函数与 Fisher 信息矩阵，严格证明了一致最小方差无偏估计（UMVUE）并达到 Cramér–Rao 下界；
\item \textbf{运筹与抽样设计支柱}：将理论方差分解与流行病学监测资源预算结合，推导了时间与样本规模的二维权衡闭式解，在数学形式上同构于经典两阶段抽样模型（Cochran 费用分配模型）的深刻对偶；
\item \textbf{经验计量与实证支柱}：不满足于纯理论推导，而是采集全美 CDC NHSN 长达六年、涵盖 50 州及 DC 的 16,218 条真实住院周度记录，采用可行广义最小二乘法（FGLS）与聚类 Bootstrap 检验，破除了达峰期“样本量失效”的传统误读，并扩展至 CDC FluSight 与欧洲 COVID-19 多场景。
\end{enumerate}

读懂这篇论文的秘诀在于：\textbf{时刻牢记“推断目标决定规模收益”这一灵魂红线}。

\section{第一部分：宏观全景地图——这篇论文究竟讲了一个什么故事？}

\subsection{1.1 一个违背直觉的现实科学矛盾}

在公共卫生监测实践与常规统计直觉中，人们往往预设：\textbf{“数据越多越好，样本量越大越准”}。大数定律告诉我们，只要不断扩大哨点医院覆盖面、增加报告确诊人数（即增大病例规模 $m$），随机噪声就会被迅速平均掉，估计精度就能无界提升。


然而，在应对流感大流行、COVID-19 等真实传染病爆发时，全球疾控机构频繁面临一个极其尴尬的困境：

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 为什么在疫情高峰期，即便每周捕获上万例患者，模型的短期预测误差依然居高不下？
\item 为什么在投入巨资扩展检测网络后，对未来趋势的判断却很快遭遇“平台瓶颈”，再怎么加倍收集病例，预测精度的改善也极其微弱？
\end{itemize}

\textbf{既有文献的局限}：以往学者通常笼统地将这种现象归咎于“漏报太多”、“数据质量差”或“模型设定错误”。近年来 Parag 等人（Nature Physics, 2022）利用信息论推导了带噪疫情曲线的信息极限，但其核心结论依然是：信息量随病例数近似线性增长。这仍未回答：\textbf{究竟在什么时候，病例规模不再是推断的主要瓶颈？}


\subsection{1.2 论文的核心破局点：“推断目标决定规模收益”}

本文最惊艳的洞见，在于指出以往文献混淆了\textbf{两个截然不同的统计推断目标}：


\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{目标 A（当期传播参数 $R_t$）}：估计特定当周环境下的瞬时传染数。此时，环境扰动是我们要测量的“信号”。定理证明：测量方差随期望报告规模 $m$ 按 $O(1/m)$ 严格单调趋零！在此目标下，大数定律完全成立，样本确实越大越好。
\item \textbf{目标 B（跨期平均基准 $\bar{R}$）}：估计消除单周偶然波动后的潜在基础趋势。此时，宏观气象、节假日人群流动等不可预测的环境扰动成了“噪声”。定理证明：单期横截面样本再大，也只能观测到该期环境的一次实现，因而必然残留一个\textbf{不可约环境方差下限 $v_R$}！总方差呈现仿射结构：
\end{itemize}
\[
\operatorname{Var} = v_R + \frac{A}{m}
\]

\subsection{1.3 内生平衡点 $m_\times$ 的物理意义}

将上述两项方差联立，自然导出了一个不可逆转的临界规模：

\[
m_\times \equiv \frac{A}{v_R}
\]

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{当 $m \ll m_\times$ 时（微观噪声主导区）}：抽样方差远远大于环境方差，此时扩大病例捕获能够带来极其显著的方差下降（投入产出比极高）；
\item \textbf{当 $m \gg m_\times$ 时（宏观环境饱和区）}：不可约环境方差占比超过 50\%，误差曲线进入水平平台。此时继续依靠扩大病例报告数已无法改善预测精度，监测资源必须由“扩量”转向“提质”（控制环境协变量与推进多模型集成）。
\end{itemize}

\subsection{2.2 核心参数的深度流行病学物理剖析}

\subsubsection{(1) 超传播参数 $k$ 的生物学本质}
在负二项分支模型中，方差公式为 $\operatorname{Var}(X) = R_t + \frac{R_t^2}{k}$。

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 第一项 $R_t$ 是纯 Poisson 计数方差（哪怕所有人传染力完全相同，随机相遇也会产生的泊松噪声）；
\item 第二项 $R_t^2/k$ 是个体生物学生殖数异质性方差。
\item \textbf{文献依据}：Lloyd-Smith 等人（Nature, 2005）对全球 8 种传染病的历史流调数据进行了元分析，发现 SARS 的 $k \approx 0.16$，麻疹 $k \approx 0.1$（强超传播），而流感 $k \approx 0.3 \sim 0.5$（中度超传播）。本文数值模拟选取 $k = 0.35$ 作为流感基准，并在实证唯象分析中覆盖 $k \in [0.2, 0.5]$，完全建立在真实流行病学基石之上。
\end{itemize}

\subsubsection{(2) 报告抽样率 $\rho$ 的折算逻辑}
在流感住院实证中，$\rho$ 不是普通的核酸阳性检出率，而是\textbf{“全社会有症状感染者最终转化为实验室确诊住院病例的复合比例”}。

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{文献依据}：
\item Zhou 等（2012）测算全美流感年均住院负担约为 20 万～40 万例；
\item Tokars 等（2018）基于血清抗体流调测算全美季节性流感平均有症状侵袭率（Symptomatic Attack Rate）约为 8\%～15\%（即约 2500 万～5000 万有症状感染）；
\item 两者相除：$\rho \approx \frac{20\text{万}}{3500\text{万}} \sim \frac{40\text{万}}{2500\text{万}} \in [0.0056, 0.021]$（千分之六至百分之二）。
\item 这一极端小概率抽样特性，完美契合了二项报告抽样模型的物理现实。
\end{itemize}

\subsubsection{(3) 滞后卷积权重 $w = (0.65, 0.25, 0.10)$ 的依据}
流感病程由三段时滞复合而成：

\begin{enumerate}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{潜伏期}：感染到出现症状，平均 1.5～2 天；
\item \textbf{就诊时滞}：发病轻症到病情恶化办理入院，平均 3～5 天；
\item \textbf{填报确认时滞}：医院实验室检测并录入 CDC NHSN 系统，平均 2～3 天。
\end{enumerate}
三者相加，流感住院的复合时滞为 8～11 天。权重向量加权时间为：

\[
\bar{\tau} = 1 \times 0.65 + 2 \times 0.25 + 3 \times 0.10 = 1.45 \text{ 周} \approx 10.2 \text{ 天}
\]
正好落在该临床生理窗口的正中心。此外，正文表 1 证明无论是单周滞后（7 天）还是三周等权（14 天），斜率 $b$ 均高度显著为正，结论对权重选择完全稳健。

\section{第三部分：数学命题教学级逐行拆解与深入证明（保姆级代数展开）}

本部分面向数学与统计学严格标准，将附录与正文中的每一个定理进行保姆级代数展开，绝不跳步。


\subsection{3.1 命题 1：条件似然、Fisher 信息与 Cramér–Rao 下界}

\subsubsection{3.1.1 定理陈述}
设已知上一代风险集真实规模 $n$、固定报告率 $\rho$ 及离散参数 $k$：

\begin{enumerate}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 观测报告数 $C_t \mid n, R_t \sim \operatorname{NB}\left(\text{均值} = \rho n R_t, \; \text{形状参数} = nk\right)$；
\item 矩估计量 $\widehat{R}_t = \frac{C_t}{\rho n}$ 恰为极大似然估计（MLE）；
\item 在内部参数空间 $R_t \in (0, \infty)$ 上，估计量 $\widehat{R}_t$ 严格无偏，且方差严格达到 Cramér–Rao 下界：
\end{enumerate}
\[
\operatorname{Var}(\widehat{R}_t \mid n, R_t) = \mathcal{I}(R_t \mid n)^{-1} = \frac{R_t}{\rho n} + \frac{R_t^2}{kn}
\]

\subsubsection{3.1.2 逐步严密代数推导}

\textbf{第一步：单感染者的概率母函数（PGF）}

个体二代感染数 $X_{i,t} \sim \operatorname{NB}(k, p)$，其中成功概率 $p = \frac{k}{k + R_t}$。

负二项分布的标准 PGF 形式为：

\[
G_X(s) \equiv \mathbb{E}[s^X] = \left(\frac{p}{1 - (1-p)s}\right)^k
\]

\textbf{第二步：$n$ 名独立感染者求和}

当期真实新发感染总数 $I_t = \sum_{i=1}^n X_{i,t}$。由条件独立性，独立随机变量和的 PGF 等于各自 PGF 之积：

\[
G_{I_t}(s) = \prod_{i=1}^n G_X(s) = \left(\frac{p}{1 - (1-p)s}\right)^{nk}
\]
因此，$I_t \mid n, R_t \sim \operatorname{NB}(nk, p)$，形状参数累加为 $nk$。


\textbf{第三步：二项报告抽样下的 PGF 复合运算}

每个感染者独立以概率 $\rho$ 上报，则报告数可表示为复合随机和 $C_t = \sum_{j=1}^{I_t} B_j$，其中 $B_j \sim \operatorname{Bernoulli}(\rho)$。

伯努利分布的 PGF 为 $G_B(s) = (1 - \rho) + \rho s$。

利用复合随机变量的 PGF 复合律 $G_{C_t}(s) = G_{I_t}(G_B(s))$：

\[
G_{C_t}(s) = \left( \frac{p}{1 - (1-p)[(1-\rho) + \rho s]} \right)^{nk}
\]
展开分母：

\[
1 - (1-p)(1-\rho) - \rho(1-p)s = [p + \rho(1-p)] - \rho(1-p)s
\]
分子分母同除以 $[p + \rho(1-p)]$：

\[
G_{C_t}(s) = \left( \frac{\frac{p}{p + \rho(1-p)}}{1 - \frac{\rho(1-p)}{p + \rho(1-p)}s} \right)^{nk}
\]
定义新的成功概率 $p^* \triangleq \frac{p}{p + \rho(1-p)}$。将 $p = \frac{k}{k + R_t}$ 及 $1-p = \frac{R_t}{k + R_t}$ 代入：

\[
p^* = \frac{\frac{k}{k + R_t}}{\frac{k}{k + R_t} + \rho \frac{R_t}{k + R_t}} = \frac{k}{k + \rho R_t}
\]
对比负二项标准 PGF 形式，直接证明了：\textbf{观测值 $C_t$ 严格服从负二项分布}：

\[
C_t \mid n, R_t \sim \operatorname{NB}\left(\text{形状参数} = nk, \; \text{成功概率} = \frac{k}{k + \rho R_t}\right)
\]
条件期望为 $\mathbb{E}[C_t] = nk \frac{1-p^*}{p^*} = \rho n R_t$。


\textbf{第四步：对数似然方程与 \texttt{const} 拆解}

观测样本 $C_t$ 的概率质量函数为：

\[
\Pr(C_t = c) = \frac{\Gamma(c + nk)}{c! \Gamma(nk)} (p^*)^{nk} (1 - p^*)^c = \left[ \frac{\Gamma(c + nk)}{c! \Gamma(nk)} \cdot k^{nk} \cdot \rho^c \right] \cdot \frac{R_t^c}{(k + \rho R_t)^{nk + c}}
\]
两边取自然对数 $\ln$：

\[
\ln L(R_t) = \underbrace{\ln\left[\frac{\Gamma(c + nk)}{c! \Gamma(nk)}\right] + nk \ln k + c \ln \rho}_{\text{与未知参数 } R_t \text{ 完全无关，简记为 } \mathbf{const}} + c \ln R_t - (nk + c) \ln(k + \rho R_t)
\]
对参数 $R_t$ 求一阶导数（得分函数 Score Function）：

\[
S(R_t) \triangleq \frac{\partial \ln L}{\partial R_t} = 0 - \frac{\rho (nk + C_t)}{k + \rho R_t} + \frac{C_t}{R_t}
\]
通分展开：

\[
S(R_t) = \frac{-\rho R_t(nk + C_t) + C_t(k + \rho R_t)}{R_t(k + \rho R_t)} = \frac{k(C_t - \rho n R_t)}{R_t(k + \rho R_t)}
\]
令得分函数为零 $S(R_t) = 0$，解得唯一驻点（极大似然估计量）：

\[
\widehat{R}_t^{\text{MLE}} = \frac{C_t}{\rho n}
\]

\textbf{第五步：无偏性验证（双层全期望展开）}

要求解 $\mathbb{E}[\widehat{R}_t \mid n, R_t]$：

\[
\mathbb{E}[\widehat{R}_t \mid n, R_t] = \mathbb{E}\left[\frac{C_t}{\rho n} \;\middle|\; n, R_t\right] = \frac{1}{\rho n} \mathbb{E}[C_t \mid n, R_t]
\]
利用双层全期望公式（塔式法则）：

\[
\mathbb{E}[C_t \mid n, R_t] = \mathbb{E}_{I_t}\Big( \mathbb{E}_{C_t}[C_t \mid I_t] \;\Big|\; n, R_t \Big)
\]
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 内层：已知真实感染 $I_t$，二项抽样均值为 $\mathbb{E}[C_t \mid I_t] = \rho I_t$；
\item 外层：已知风险集 $n$ 和传播率 $R_t$，各分支独立，感染总数期望为 $\mathbb{E}[I_t \mid n, R_t] = n R_t$；
\end{itemize}
代入得：

\[
\mathbb{E}[C_t \mid n, R_t] = \mathbb{E}[\rho I_t \mid n, R_t] = \rho \mathbb{E}[I_t \mid n, R_t] = \rho n R_t
\]
两端相除：

\[
\mathbb{E}[\widehat{R}_t \mid n, R_t] = \frac{\rho n R_t}{\rho n} = R_t
\]
\textbf{无偏性证毕！}


\textbf{第六步：Fisher 信息量两套算法与 Cramér–Rao 下界}

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{算法一（得分方差法）}：
\end{itemize}
\[
\mathcal{I}(R_t \mid n) = \operatorname{Var}(S(R_t)) = \frac{k^2}{R_t^2(k + \rho R_t)^2} \operatorname{Var}(C_t \mid n, R_t)
\]
代入负二项方差 $\operatorname{Var}(C_t) = \frac{\rho n R_t (k + \rho R_t)}{k}$：

\[
\mathcal{I}(R_t \mid n) = \frac{k^2 \cdot \frac{\rho n R_t (k + \rho R_t)}{k}}{R_t^2(k + \rho R_t)^2} = \frac{k \rho n}{R_t(k + \rho R_t)} = \frac{n}{\frac{R_t}{\rho} + \frac{R_t^2}{k}}
\]
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{算法二（负二阶导期望法）}：
\end{itemize}
对得分函数 $S(R_t) = -\frac{\rho(nk + C_t)}{k + \rho R_t} + \frac{C_t}{R_t}$ 再次求导：

\[
\frac{\partial^2 \ln L}{\partial R_t^2} = \frac{\rho^2(nk + C_t)}{(k + \rho R_t)^2} - \frac{C_t}{R_t^2}
\]
取负号并求期望，代入 $\mathbb{E}[C_t] = \rho n R_t$：

\[
\mathcal{I}(R_t \mid n) = \mathbb{E}\left[\frac{C_t}{R_t^2} - \frac{\rho^2(nk + C_t)}{(k + \rho R_t)^2}\right] = \frac{\rho n R_t}{R_t^2} - \frac{\rho^2(nk + \rho n R_t)}{(k + \rho R_t)^2} = \frac{\rho n}{R_t} - \frac{\rho^2 n}{k + \rho R_t} = \frac{k \rho n}{R_t(k + \rho R_t)}
\]
两套算法完全一致！计算其倒数：

\[
\mathcal{I}(R_t \mid n)^{-1} = \frac{R_t}{\rho n} + \frac{R_t^2}{kn}
\]
由于估计量无偏，Cramér–Rao 方差下界恰为 $\mathcal{I}^{-1}$，而估计量方差代数上严格等于该倒数。

\textbf{证毕}：估计量为 UMVUE。

\subsection{3.2 命题 2：跨期基础水平的边际方差分解}

\subsubsection{3.2.1 定理陈述}
估计跨期平均传播基准 $\bar{R} \equiv \mathbb{E}[R_t \mid n]$（存在宏观环境随机性 $\operatorname{Var}(R_t \mid n) = v_R > 0$），单期估计量 $\frac{C_t}{\rho n}$ 给定风险集 $n$ 的条件边际方差为：

\[
\operatorname{Var}\left(\frac{C_t}{\rho n} \;\middle|\; n\right) = v_R + \frac{\bar{R}}{\rho n} + \frac{\bar{R}^2 + v_R}{kn} \equiv v_R + \frac{A}{m}
\]
其中期望报告规模 $m \equiv \rho n$，标量系数 $A \equiv \bar{R} + \frac{\rho(\bar{R}^2 + v_R)}{k}$。


\subsubsection{3.2.2 逐步严密代数推导}
应用\textbf{全方差公式（Law of Total Variance）}：

\[
\operatorname{Var}\left(\frac{C_t}{\rho n} \;\middle|\; n\right) = \underbrace{\operatorname{Var}\left( \mathbb{E}\left[\frac{C_t}{\rho n} \;\middle|\; n, R_t\right] \;\middle|\; n \right)}_{\text{宏观环境方差贡献}} + \underbrace{\mathbb{E}\left[ \operatorname{Var}\left(\frac{C_t}{\rho n} \;\middle|\; n, R_t\right) \;\middle|\; n \right]}_{\text{微观抽样方差贡献}}
\]

\textbf{第一项计算}：

由命题 1 的无偏性结论，$\mathbb{E}\left[\frac{C_t}{\rho n} \;\middle|\; n, R_t\right] = R_t$。因此：

\[
\operatorname{Var}(R_t \mid n) = v_R
\]

\textbf{第二项计算}：

代入命题 1 导出的条件方差式：

\[
\mathbb{E}\left[ \frac{R_t}{\rho n} + \frac{R_t^2}{kn} \;\middle|\; n \right] = \frac{\mathbb{E}[R_t \mid n]}{\rho n} + \frac{\mathbb{E}[R_t^2 \mid n]}{kn}
\]
由二阶矩与方差的基本代数关系：$\mathbb{E}[R_t^2 \mid n] = \operatorname{Var}(R_t \mid n) + (\mathbb{E}[R_t \mid n])^2 = v_R + \bar{R}^2$。

代入得：

\[
= \frac{\bar{R}}{\rho n} + \frac{\bar{R}^2 + v_R}{kn}
\]

两项相加，得到定稿核心方差公式：

\[
\operatorname{Var}\left(\frac{C_t}{\rho n} \;\middle|\; n\right) = v_R + \frac{\bar{R}}{\rho n} + \frac{\bar{R}^2 + v_R}{kn} = v_R + \frac{1}{\rho n}\left[\bar{R} + \frac{\rho(\bar{R}^2 + v_R)}{k}\right] = v_R + \frac{A}{m}
\]
\textbf{物理含义}：单期方差呈现严格的仿射结构 $v_R + A/m$。当 $m \to \infty$ 时，后项抽样方差消失，但前项宏观环境方差 $v_R$ 永远保留！

\subsection{3.3 命题 3：监测杠杆的理论非对称性}

\subsubsection{3.3.1 定理陈述}
将单期方差中的抽样项展开：

\[
\frac{\bar{R}}{\rho n} = \frac{\bar{R}}{n} + \frac{(1-\rho)\bar{R}}{\rho n}
\]
总方差二元函数 $V(n, \rho)$ 满足：

\begin{enumerate}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 报告率极限（$\rho \to 1$）：$\lim_{\rho \to 1} V(n, \rho) = v_R + \frac{\bar{R}}{n} + \frac{\bar{R}^2 + v_R}{kn} > v_R$；
\item 风险集基数极限（$n \to \infty$）：$\lim_{n \to \infty} V(n, \rho) = v_R$。
\end{enumerate}

\subsubsection{3.3.2 严密分步极限推导}
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{对报告率 $\rho \to 1$ 求极限}：
\end{itemize}
\[
\lim_{\rho \to 1} V(n, \rho) = v_R + \lim_{\rho \to 1} \frac{(1-\rho)\bar{R}}{\rho n} + \frac{\bar{R}}{n} + \frac{\bar{R}^2 + v_R}{kn} = v_R + 0 + \frac{\bar{R}}{n} + \frac{\bar{R}^2 + v_R}{kn} > v_R
\]
\textbf{解释}：完全消除漏报只能干掉 $\frac{(1-\rho)\bar{R}}{\rho n}$，但人群内部固有的完全报告泊松计数波动 $\bar{R}/n$ 和超级传播子代抽样波动 $\frac{\bar{R}^2+v_R}{kn}$ 均依赖于有限样本量 $n$，无法靠提升报告率解决。

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{对人群基数 $n \to \infty$ 求极限}：
\end{itemize}
\[
\lim_{n \to \infty} V(n, \rho) = v_R + \lim_{n \to \infty}\frac{1}{n} \left[ \frac{\bar{R}}{\rho} + \frac{\bar{R}^2 + v_R}{k} \right] = v_R + 0 = v_R
\]
\textbf{解释}：扩大基数 $n$ 分母趋于无穷大，利用大数定律将所有微观层面的抽样波动彻底消除。

\subsection{3.4 命题 4 与推论 1：成本预算与监测设计运筹优化}

\subsubsection{3.4.1 命题 4（多期时间平均与 AR(1) 修正）}
设总样本输入规模预算为 $B = T \cdot m = T \rho n_T$。设计方案为 $\mathcal{D}_T = (T, n_T)$。

对跨期样本均值 $\overline{\widehat{R}}_T = \frac{1}{T}\sum_{t=1}^T \widehat{R}_t$ 求方差：

\[
\operatorname{Var}(\overline{\widehat{R}}_T) = \frac{1}{T^2}\operatorname{Var}\left(\sum_{t=1}^T R_t\right) + \frac{1}{T^2}\sum_{t=1}^T \operatorname{Var}(\widehat{R}_t \mid R_t) = \frac{1}{T^2}\operatorname{Var}\left(\sum_{t=1}^T R_t\right) + \frac{1}{T^2} \cdot T \frac{A}{m}
\]
代入 $T m = B$：

\[
\text{第二项（抽样项）} = \frac{A}{T m} = \frac{A}{B} \quad (\text{恒为常数！})
\]
\textbf{惊人结论}：在固定总样本预算下，无论你分多少期，抽样误差项永远是常数 $A/B$！

要想降低总方差，\textbf{唯一的方法是拉长期数 $T$ 去压制第一项（环境项）}！

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 独立环境下：第一项为 $\frac{v_R}{T}$，方差以 $O(1/T)$ 严格递减；
\item AR(1) 自相关环境下（相关系数 $r$）：
\end{itemize}
\[
\operatorname{Var}\left(\sum_{t=1}^T R_t\right) = T v_R + 2 v_R \sum_{s=1}^{T-1}(T-s)r^s = v_R T \left[ \frac{1+r}{1-r} - \frac{2r(1-r^T)}{T(1-r)^2} \right]
\]
当观测期远大于环境自相关记忆时长（$T \gg \frac{1}{1-r}$）时，有效独立期数退化为 $T_{\mathrm{eff}} \approx T \frac{1-r}{1+r}$。


\subsubsection{3.4.2 推论 1（成本约束下的闭式解与 Cochran 对偶）}
设每期固定运转维持成本为 $c_0$，每报告一例边际成本为 $c_1$。总经费预算为 $\mathcal{B} = T(c_0 + c_1 m)$。

代入 $T = \frac{\mathcal{B}}{c_0 + c_1 m}$ 到目标方差函数：

\[
f(m) = \operatorname{Var}(\overline{\widehat{R}}_T) = \frac{v_R}{\frac{\mathcal{B}}{c_0 + c_1 m}} + \frac{A}{\frac{\mathcal{B}}{c_0 + c_1 m} m} = \frac{c_0 + c_1 m}{\mathcal{B}} \left( v_R + \frac{A}{m} \right) = \frac{1}{\mathcal{B}} \left[ c_0 v_R + c_1 v_R m + \frac{c_0 A}{m} + c_1 A \right]
\]
\textbf{求一阶导数}：

\[
f'(m) = \frac{1}{\mathcal{B}} \left[ c_1 v_R - \frac{c_0 A}{m^2} \right] = 0 \implies m^2 = \frac{c_0 A}{c_1 v_R} = \frac{c_0}{c_1} m_\times \implies m^* = \sqrt{\frac{c_0}{c_1} m_\times}
\]
\textbf{求二阶导数}：

\[
f''(m) = \frac{2 c_0 A}{\mathcal{B} m^3} > 0 \quad (\text{对一切 } m>0 \text{ 恒正，函数严格凸！})
\]
\textbf{学术高度}：这在数学结构上与抽样调查鼻祖 Cochran (1977) 第 10 章的两阶段抽样最优次级样本量公式完全同构！初级抽样单元对应期数 $T$，次级抽样单元对应单期病例 $m$。

\subsection{3.5 命题 5：当期超临界增长判定的精确检验与离散功效锯齿}

\subsubsection{3.5.1 检验构建与单调似然比（MLR）}
单侧假设检验：$H_0: R_t \le 1 \quad \text{vs} \quad H_1: R_t > 1$。

对任意 $R_1 > R_0$，似然比为：

\[
\frac{\Pr_{R_1}(C_t = j)}{\Pr_{R_0}(C_t = j)} = \left(\frac{p^*(R_1)}{p^*(R_0)}\right)^{nk} \left(\frac{1 - p^*(R_1)}{1 - p^*(R_0)}\right)^j
\]
由于 $1 - p^*(R) = \frac{\rho R}{k + \rho R}$ 关于 $R$ 严格单调递增，底数 $\frac{1 - p^*(R_1)}{1 - p^*(R_0)} > 1$。

因此，似然比关于充分统计量 $C_t$ \textbf{严格单调递增}（满足 MLR 性质）。

由经典统计推断理论（Karlin–Rubin 定理），上尾拒绝域 $\{C_t \ge c_\alpha\}$ 在复合原假设下，一类错误率严格在上确界点（边界点 $R_t = 1$）达到最大：

\[
\sup_{R_t \le 1} \Pr_{R_t}(C_t \ge c_\alpha) = \Pr_{R_t = 1}(C_t \ge c_\alpha) \le \alpha
\]
离散临界值由 $c_\alpha = \min \{c \in \mathbb{N} : \Pr_{R_t=1}(C_t \ge c) \le \alpha\}$ 唯一确定。


\subsubsection{3.5.2 为什么功效曲线呈现锯齿状（Sawtooth Wave）？}
因为观测计数 $C_t$ 只能取整数，临界值 $c_\alpha(n)$ 随样本量 $n$ 呈阶梯状跳变：

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 当 $n$ 在某个区间连续微增时，临界值 $c_\alpha$ 保持不变，由于样本量变大，功效连续上升；
\item 一旦 $n$ 跨过某个临界点，为了控制显著性水平 $\alpha$，$c_\alpha$ 突然跳跃到 $c_\alpha + 1$，拒绝门槛突然拔高，导致统计功效瞬间出现向下跳跃！
\item 这解释了图 2 模拟中为什么连续增加病例数，功效曲线会出现特有的锯齿波动，证实了离散枚举求解最小样本量的必要性。
\end{itemize}

\section{第五部分：全美流感真实数据实证全景复盘}

\subsection{5.1 数据资产与计量模型设定}
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{真实数据源}：美国 CDC NHSN 系统 50 个州加华盛顿特区自 2020 年 8 月至 2026 年 9 月共 16,218 条周度住院记录；
\item \textbf{有效样本筛选}：$D_t \ge 5$（活跃周门槛），保留 10,303 个有效州周观测；
\item \textbf{计量模型}：根据式 (7) 仿射理论形式，建立模型 $\operatorname{Loss}_{s,t} = a + \frac{b}{D_{s,t}} + u_{s,t}$；
\item \textbf{为什么必须用 FGLS（可行广义最小二乘法）？}
\item 普通 OLS 假定误差项具有同方差；
\item 但实测发现：残差具有极端厚尾（偏度高达 8.63），且小规模组的方差--均值比高达 5.32，大规模组收缩至 0.99，存在剧烈的反比非齐次方差；
\item 必须采用以拟合值平方倒数 $1/\hat{\mu}^2$ 加权的 FGLS，并配合 1,500 次按州聚类的 Bootstrap 估计标准误。
\end{itemize}

\subsection{5.2 核心实证估计结果}
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 规模斜率项 $\hat{b} = 2.2434$（95\% CI $[1.50, 3.02]$），\textbf{1,500 次 Bootstrap 重抽无一次小于等于零（$p < 10^{-4}$）}，强力证实了 $b/D_t$ 递减项的真实存在；
\item 经验拟合截距 $\hat{a} = 0.0991$；经验平衡点 $m_\times^{\mathrm{emp}} = \hat{b}/\hat{a} \approx 22.6$ 例/周；
\item \textbf{误差份额分解}：在流行初期平均 0.181 的总误差中，规模相关项占 45.1\%，不可约经验下限占 54.6\%（四至五成半）。
\end{itemize}

\item \textbf{论文的数学正交分解}：
\end{itemize}

\text{总误差} = \underbrace{\left(\frac{\bar{R}_{\mathrm{peak}} - \bar{R}_{\mathrm{early}}}{\bar{R}_{\mathrm{early}}}\right)^2}_{\text{常数基准偏移项（占 88.9\%）}} + \underbrace{\text{条件方差项（占 11.1\%）}}_{\text{规模效应仍显著为正！}}

\item 达峰期看似恒定的高误差，\textbf{整整 88.9\% 是因为疫情达峰转向、历史平稳基准失灵导致的常数漂移}！

\item \textbf{外部验证的终极呼应}：
\end{itemize}
在引入 CDC FluSight 官方真实多模型前瞻集成预测后，\textbf{达峰期的均值偏差占比从静态单模型的 88.9\% 骤降至 15.5\%}！

\section{第六部分：硕士中期答辩高频质询 Q\&A 宝典（10 问 10 答）}

本部分专为数学系、应用统计系教授评委的刁钻提问量身定制，掌握这 10 个回答，答辩即可稳操胜券。


\subsubsection{Q1: 你的研究与现有的 EpiEstim (Cori) 和 Parag 的信息论下界有什么本质区别？}
> \textbf{答}：Cori 等人的 EpiEstim 解决的是“如何在滑动窗口下估计时变再生数”，Parag 等人的研究确立了“以当期瞬态参数 $R_t$ 为目标时信息量随病例数线性增长”的物理极限。

> 本文的本质区别在于\textbf{推断目标的切换}：我们证明，一旦将推断目标由当期瞬态参数 $R_t$ 切换为跨期基础水平 $\bar{R}$，由于单期横截面样本无法消除全员共享的外生宏观环境扰动，方差标度律发生根本改变，出现不可约环境方差下限 $v_R$ 与特征规模平衡点 $m_\times$。本文填补的是从“单期推断”跨越到“监测资源运筹设计”的理论空白。


\subsubsection{Q2: 为什么一定要用负二项分支过程？用经典的泊松过程不行吗？}
> \textbf{答}：传染病学中普遍存在极强的超传播现象（Lloyd-Smith 等 2005），约 20\% 的感染者引发 80\% 的传播。

> 泊松分布强加了方差等于均值（$k \to \infty$），这在数学上会严重低估小计数阶段的重尾抽样风险，人为低估达到指定功效所需的样本量需求（如图 2 所示，强超传播下样本量需求暴增 3 倍）。引入负二项分布不仅具有流行病学真实性，更在数理上通过 PGF 复合运算保证了二项抽样下的分布族封闭性，为全方差分解提供了优雅的解析基准。


\subsubsection{Q3: 理论上的 $m_\times = A/v_R$ 与实证拟合得到的 $b/a \approx 22.6$ 能否直接画等号？}
> \textbf{答}：不能直接等同，实证比值是理论平衡点的\textbf{经验映射物与量级参照}。

> 理论上的 $m_\times$ 是在单代已知参数下的解析临界点；而实证中的 $a = 0.0991$ 与 $b = 2.2434$ 是在真实流感周度时间序列中对 $D_t$ 进行仿射拟合的参数，其中 $a$ 既包含了宏观环境波动，也吸收了滞后卷积平滑失配的常数偏差。实证的核心价值在于\textbf{验证了理论预测的仿射递减与平台收敛形状}，而非点位精确物理测量。


\subsubsection{Q4: 你在局限性里提到 $v_R$ 始终是拟合量而非测量量，如果让你来测，在实务中怎么才能把它测出来？}
> \textbf{答}：正如我们在第 6.2 节方法学展望中所提出的，未来可以通过\textbf{“双轨监测体系”}实现纯外生环境方差 $v_R$ 的解耦测度：

> 目前的医院住院监测混合了就医行为与填报时滞；如果能在代表性社区布设固定人群的前瞻性主动追踪队列（如定期家庭采样），直接测得无就医行为干扰的真实社区传播强度，就能将外生宏观环境方差 $v_R$ 与监测系统的代理平滑偏差完全分离识别。


\subsubsection{Q5: 为什么推论 1 里的最优单期规模公式会和 Cochran 的两阶段抽样同构？}
> \textbf{答}：这体现了数理统计深层的对偶之美。

> 在时间序列监测中，期数 $T$ 本质上就是初级抽样单元（PSU），单期捕获病例数 $m$ 就是次级抽样单元（SSU）。固定维持成本 $c_0$ 发生于每一期，边际采集成本 $c_1$ 发生于每个病例。这与 Cochran (1977) 调查抽样中“在有限预算下权衡抽取多少个群（群成本 $c_0$）与每群调查多少人（人均成本 $c_1$）”的数学优化模型完全同构，二阶导数 $\frac{2c_0 A}{\mathcal{B} m^3} > 0$ 严格保证了最优解的全局唯一性。


\subsubsection{Q6: 实证中为什么用 FGLS 而不用我们最熟悉的普通最小二乘法 (OLS)？}
> \textbf{答}：因为真实监测数据的残差具有极强的异方差与厚尾性。

> 流感住院损失的偏度高达 8.63，小规模段的方差--均值比高达 5.32，大规模段收缩至 0.99，表现出剧烈的反比非齐次方差。如果使用普通 OLS，小样本段的极大极端值会过度主导回归线，估计功效损失极大；FGLS 通过一阶拟合残差平方倒数进行迭代加权，在大样本下达到最优线性无偏估计（BLUE）。


\subsubsection{Q7: 达峰期看似误差恒定在 0.3 左右，你凭什么说病例规模在达峰期依然有用？}
> \textbf{答}：凭严格的\textbf{均值--方差正交代数分解}。

> 我们证明了达峰期看似恒定的高误差中，整整 88.9\% 来源于疫情转折导致的常数基准漂移 $(\bar{R}_{\mathrm{peak}} - \bar{R}_{\mathrm{early}})^2 / \bar{R}_{\mathrm{early}}^2 = 0.2669$。真正反映推断波动的纯条件方差只占 11.1\%。当我们使用达峰期自身均值剥离常数漂移后，规模相关项系数 $\hat{b} = 7.9272$ 依然高度显著为正。失效的是跨期平稳性假设，而不是病例规模本身。


\subsubsection{Q8: 滞后暴露权重取 $w = (0.65, 0.25, 0.10)$ 的依据是什么？换一组权重结论还成立吗？}
> \textbf{答}：有两个依据：第一，加权平均回溯时间为 $1.45$ 周（约 $10.2$ 天），与流感临床从感染、潜伏（1–2天）、发病就诊（3–5天）到填报确认的复合特征时滞（约 10 天）完全吻合；

> 第二，正文第 5.1 节进行了严格的权重敏感性检验：无论换用单周滞后（7天）还是三周等权（14天），规模斜率 $b$ 始终在 $1.9$ 到 $3.1$ 之间，聚类 Bootstrap 置信区间严格远离零点，1,500 次重抽无一次小于零，核心科学结论对权重设定高度稳健。


\subsubsection{Q9: 为什么命题 3 说提高报告率 $\rho$ 存在无法消除的方差下界？现实中疾控提高检测率没有意义吗？}
> \textbf{答}：提高报告率具有显著价值，但它的作用机制具有局限性。

> 全方差公式严格表明：提高报告率 $\rho \to 1$ 只能消除由于漏报产生的纯二项抽样方差 $\frac{(1-\rho)\bar{R}}{\rho n}$，但它无法消除人群中固有的微观计数随机性 $\frac{\bar{R}}{n}$，更无法消除个体超级传播引发的子代抽样方差 $\frac{\bar{R}^2+v_R}{kn}$。唯有扩大地理或人群基数 $n$，通过大数定律才能同时压低所有微观随机性。


\subsubsection{Q10: 这篇论文对国家公共卫生监测体系的建设，到底能提供什么实际建议？}
> \textbf{答}：给出了两阶段“差异化资源配置”判据：

> 1. \textbf{在疫情初期与低发期（$m < m_\times$）}：系统处于微观噪声主导区，此时应集中资源扩建哨点、扩大病例捕获，能够迅速跨过平衡点，获得显著的方差收益；

> 2. \textbf{在疫情高峰期与常态化监测期（$m > m_\times$）}：系统跨过特征平衡点进入饱和区，此时继续单纯追求捕获更多病例已边际收益递减，监测资源应当果断由“扩量”转向“提质”——即转向引入多模型前瞻集成预测，并补充气象、人群流动等外部环境协变量以解释不可约环境方差。
