\section{导读前言：应用统计研究生的“论文通透心法”}

阅读或答辩这篇论文时，首先要建立一个宏观全局认知：\textbf{本文是一篇高度典范的应用统计学顶刊风格论文}。它的行文与论证结构高度精密，由四根核心支柱环环相扣而成：


\begin{enumerate}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{微观概率论支柱}：从经典生灭分支过程（Galton–Watson 过程）出发，引入生物学超传播机制（Gamma 混合泊松分布，即负二项分布）与宏观观测不完全性（二项报告抽样过程），建立了双层随机生成机制；
\item \textbf{渐近统计推断支柱}：利用概率母函数（PGF）复合律证明了分布族闭包，计算得分函数与 Fisher 信息矩阵，严格证明了一致最小方差无偏估计（UMVUE）并达到 Cramér–Rao 下界；
\item \textbf{运筹与抽样设计支柱}：将理论方差分解与流行病学监测资源预算结合，推导了时间与样本规模的二维权衡闭式解，在数学形式上同构于经典两阶段抽样模型（Cochran 费用分配模型）；
\item \textbf{经验计量与实证支柱}：不满足于纯理论推导，而是采集全美 CDC NHSN 长达六年、涵盖 50 州及 DC 的 16,218 条真实住院周度记录，采用可行广义最小二乘法（FGLS）与聚类 Bootstrap 检验，破除了达峰期“样本量失效”的传统误读，并扩展至 CDC FluSight 与欧洲 COVID-19 多场景。
\end{enumerate}

\section{第一部分：宏观全景地图——这篇论文究竟讲了一个什么故事？}

\subsection{1.1 一个违背直觉的现实科学矛盾}

在公共卫生监测实践与常规统计直觉中，人们往往预设：\textbf{“数据越多越好，样本量越大越准”}。大数定律告诉我们，只要不断扩大哨点医院覆盖面、增加报告确诊人数（即增大病例规模 $m$），随机噪声就会被迅速平均掉，估计精度就能无界提升。


然而，在应对流感大流行、COVID-19 等真实传染病爆发时，全球疾控机构频繁面临一个极其尴尬的困境：

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 为什么在疫情高峰期，即便每周捕获上万例患者，模型的短期预测误差依然居高不下？
\item 为什么在投入巨资扩展检测网络后，对未来趋势的判断却很快遭遇“平台瓶颈”，再怎么加倍收集病例，预测精度的改善也极其微弱？
\end{itemize}

\textbf{既有文献的局限}：以往学者通常笼统地将这种现象归咎于“漏报太多”、“数据质量差”或“模型设定错误”。近年来 Parag 等人（Nature Physics, 2022）利用信息论推导了带噪疫情曲线的信息极限，但其核心结论依然是：信息量随病例数近似线性增长。这仍未回答：\textbf{究竟在什么时候，病例规模不再是推断的主要瓶颈？}


\subsection{1.2 论文的核心破局点：“推断目标决定规模收益”}

本文最惊艳的洞见，在于指出以往文献混淆了\textbf{两个截然不同的统计推断目标}：


\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{目标 A（当期传播参数 $R_t$）}：估计特定当周环境下的瞬时传染数。此时，环境扰动是我们要测量的“信号”。定理证明：测量方差随期望报告规模 $m$ 按 $O(1/m)$ 严格单调趋零！在此目标下，大数定律完全成立，样本确实越大越好。
\item \textbf{目标 B（跨期平均基准 $\bar{R}$）}：估计消除单周偶然波动后的潜在基础趋势。此时，宏观气象、节假日人群流动等不可预测的环境扰动成了“噪声”。定理证明：单期横截面样本再大，也只能观测到该期环境的一次实现，因而必然残留一个\textbf{不可约环境方差下限 $v_R$}！总方差呈现仿射结构：
\end{itemize}
\[
\operatorname{Var} = v_R + \frac{A}{m}
\]

\subsection{1.3 内生平衡点 $m_\times$ 的物理意义}

将上述两项方差联立，自然导出了一个不可逆转的临界规模：

\[
m_\times \equiv \frac{A}{v_R}
\]

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{当 $m \ll m_\times$ 时（微观噪声主导区）}：抽样方差远远大于环境方差，此时扩大病例捕获能够带来极其显著的方差下降（投入产出比极高）；
\item \textbf{当 $m \gg m_\times$ 时（宏观环境饱和区）}：不可约环境方差占比超过 50\%，误差曲线进入水平平台。此时继续依靠扩大病例报告数已无法改善预测精度，监测资源必须由“扩量”转向“提质”（控制环境协变量与推进多模型集成）。
\end{itemize}

\subsection{2.2 核心参数的深度流行病学物理剖析}

\subsubsection{(1) 超传播参数 $k$ 的生物学本质}
在负二项分支模型中，方差公式为 $\operatorname{Var}(X) = R_t + \frac{R_t^2}{k}$。

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 第一项 $R_t$ 是纯 Poisson 计数方差（哪怕所有人传染力完全相同，随机相遇也会产生的泊松噪声）；
\item 第二项 $R_t^2/k$ 是个体生物学生殖数异质性方差。
\item \textbf{文献依据}：Lloyd-Smith 等人（Nature, 2005）对全球 8 种传染病的历史流调数据进行了元分析，发现 SARS 的 $k \approx 0.16$，麻疹 $k \approx 0.1$（强超传播），而流感 $k \approx 0.3 \sim 0.5$（中度超传播）。本文数值模拟选取 $k = 0.35$ 作为流感基准，并在实证唯象分析中覆盖 $k \in [0.2, 0.5]$，完全建立在真实流行病学基石之上。
\end{itemize}

\subsubsection{(2) 报告抽样率 $\rho$ 的折算逻辑}
在流感住院实证中，$\rho$ 不是普通的核酸阳性检出率，而是\textbf{“全社会有症状感染者最终转化为实验室确诊住院病例的复合比例”}。

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{文献依据}：
\item Zhou 等（2012）测算全美流感年均住院负担约为 20 万～40 万例；
\item Tokars 等（2018）基于血清抗体流调测算全美季节性流感平均有症状侵袭率（Symptomatic Attack Rate）约为 8\%～15\%（即约 2500 万～5000 万有症状感染）；
\item 两者相除：$\rho \approx \frac{20\text{万}}{3500\text{万}} \sim \frac{40\text{万}}{2500\text{万}} \in [0.0056, 0.021]$（千分之六至百分之二）。
\item 这一极端小概率抽样特性，完美契合了二项报告抽样模型的物理现实。
\end{itemize}

\subsubsection{(3) 滞后卷积权重 $w = (0.65, 0.25, 0.10)$ 的依据}
流感病程由三段时滞复合而成：

\begin{enumerate}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{潜伏期}：感染到出现症状，平均 1.5～2 天；
\item \textbf{就诊时滞}：发病轻症到病情恶化办理入院，平均 3～5 天；
\item \textbf{填报确认时滞}：医院实验室检测并录入 CDC NHSN 系统，平均 2～3 天。
\end{enumerate}
三者相加，流感住院的复合时滞为 8～11 天。权重向量加权时间为：

\[
\bar{\tau} = 1 \times 0.65 + 2 \times 0.25 + 3 \times 0.10 = 1.45 \text{ 周} \approx 10.2 \text{ 天}
\]
正好落在该临床生理窗口的正中心。此外，正文表 1 证明无论是单周滞后（7 天）还是三周等权（14 天），斜率 $b$ 均高度显著为正，结论对权重选择完全稳健。

\subsection{3.1 命题 1 前置：Gamma–Poisson 混合积分逐行展开与“成功概率” $p$ 的物理本质}

\subsubsection{3.1.0 成功概率 $p$ 的反直觉物理顿悟}
在负二项分布 $\operatorname{NB}(k, p)$ 的抛硬币定义中：

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 我们不断试验，直到累计看到第 $k$ 次“成功”为止；
\item 在此之前所经历的“失败总次数” $X$ 服从负二项分布。
\item \textbf{在传染病模型中}：
\item \textbf{传染给一个人 $\Longrightarrow$ 数学上记为一次“失败”}！
\item \textbf{传染链条中断（未传染） $\Longrightarrow$ 数学上记为一次“成功”}！
\item 均值公式反解：
\end{itemize}
\[
R_t = k \frac{1-p}{p} \implies p R_t = k - kp \implies p(k + R_t) = k \implies p = \frac{k}{k + R_t}
\]
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{物理直觉}：病毒传染力越强（$R_t$ 越大），“中断传染（成功）”的概率 $p$ 越接近 0，于是在链条中断前就会发生大量的“传染事件（失败）”，造成超级暴发！
\end{itemize}

\subsubsection{3.1.1 Gamma–Poisson 连续混合积分逐行演算}
设个体传染力 $\nu \sim \operatorname{Gamma}(k, \theta)$，其中形状参数为 $k$，尺度参数 $\theta = R_t/k$。概率密度为：

\[
f_\nu(\nu) = \frac{1}{\theta^k \Gamma(k)} \nu^{k-1} e^{-\nu/\theta} = \frac{(k/R_t)^k}{\Gamma(k)} \nu^{k-1} e^{-k\nu / R_t}
\]
给定个体传染力 $\nu$，二代感染数条件服从泊松分布：$\Pr(X = x \mid \nu) = \frac{\nu^x e^{-\nu}}{x!}$。

对潜变量 $\nu$ 在 $(0, \infty)$ 上求全积分（边缘化）：

\[
\Pr(X = x) = \int_0^\infty \frac{\nu^x e^{-\nu}}{x!} \cdot \frac{(k/R_t)^k}{\Gamma(k)} \nu^{k-1} e^{-k\nu / R_t} d\nu
\]
提取所有不含积分变量 $\nu$ 的常数项，合并被积函数中的幂次与指数：

\[
= \frac{(k/R_t)^k}{x! \Gamma(k)} \int_0^\infty \nu^{(x+k)-1} \exp\left\{ -\nu \left(1 + \frac{k}{R_t}\right) \right\} d\nu
\]
做变量代换：令 $u = \nu \left(1 + \frac{k}{R_t}\right) = \nu \frac{k + R_t}{R_t}$，则 $\nu = u \frac{R_t}{k + R_t}$，微元 $d\nu = \frac{R_t}{k + R_t} du$。

代入积分中：

\[
\int_0^\infty \nu^{(x+k)-1} e^{-u} \frac{R_t}{k + R_t} du = \left(\frac{R_t}{k + R_t}\right)^{x+k} \int_0^\infty u^{(x+k)-1} e^{-u} du
\]
由欧拉 Gamma 函数严格积分定义：$\int_0^\infty u^{(x+k)-1} e^{-u} du = \Gamma(x+k)$！

代回原式展开：

\[
\Pr(X = x) = \frac{(k/R_t)^k}{x! \Gamma(k)} \cdot \left(\frac{R_t}{k + R_t}\right)^{x+k} \cdot \Gamma(x+k) = \frac{\Gamma(x+k)}{x! \Gamma(k)} \cdot \frac{k^k R_t^x}{(k + R_t)^{x+k}}
\]
按幂次项拆分组合：

\[
= \frac{\Gamma(x+k)}{x! \Gamma(k)} \cdot \left(\frac{k}{k + R_t}\right)^k \left(\frac{R_t}{k + R_t}\right)^x
\]
令 $p \triangleq \frac{k}{k + R_t}$，则 $1 - p = 1 - \frac{k}{k + R_t} = \frac{R_t}{k + R_t}$。

代入即得：

\[
\Pr(X = x) = \frac{\Gamma(x+k)}{x! \Gamma(k)} p^k (1 - p)^x \equiv \operatorname{NB}(k, p)
\]
\textbf{从微观连续混合积分到离散负二项 PMF 逐行证毕！}

\subsubsection{3.2.1 PGF 复合律保族性逐行推导}
每个感染者独立以概率 $\rho$ 上报，报告数 $C_t = \sum_{j=1}^{I_t} B_j$，其中 $B_j \sim \operatorname{Bernoulli}(\rho)$，其 PGF 为 $G_B(s) = (1 - \rho) + \rho s$。

上一代 $n$ 个人产生的感染总数 $I_t \sim \operatorname{NB}(nk, p)$，其 PGF 为：

\[
G_{I_t}(s) = \left(\frac{p}{1 - (1-p)s}\right)^{nk}
\]
利用复合随机和 PGF 复合定理 $G_{C_t}(s) = G_{I_t}(G_B(s))$：

\[
G_{C_t}(s) = \left( \frac{p}{1 - (1-p)[(1-\rho) + \rho s]} \right)^{nk}
\]
将分母完全展开：

\[
1 - (1-p)(1-\rho) - \rho(1-p)s = 1 - (1 - \rho - p + p\rho) - \rho(1-p)s = [p + \rho(1-p)] - \rho(1-p)s
\]
分子分母同时除以提取因子 $[p + \rho(1-p)]$：

\[
G_{C_t}(s) = \left( \frac{\frac{p}{p + \rho(1-p)}}{1 - \frac{\rho(1-p)}{p + \rho(1-p)}s} \right)^{nk}
\]
定义新成功概率 $p^* \triangleq \frac{p}{p + \rho(1-p)}$。代入 $p = \frac{k}{k+R_t}$ 与 $1-p = \frac{R_t}{k+R_t}$：

\[
p^* = \frac{\frac{k}{k + R_t}}{\frac{k}{k + R_t} + \rho \frac{R_t}{k + R_t}} = \frac{k}{k + \rho R_t}
\]
对比负二项标准 PGF 形式，直接证明了：\textbf{观测值 $C_t \mid n, R_t \sim \operatorname{NB}(nk, p^*)$ 严格保族封闭！}

\end{quote}

\begin{equation*}
C_t \mid n, R_t \sim \operatorname{NB}\!\left(\text{均值} = \rho n R_t, \; \text{形状参数} = nk\right) \tag{eq:nb\_thinning}
\end{equation*}
\end{quote}

\subsubsection{3.2.2 负二项方差公式化简}
由负二项分布方差公式，形状参数为 $nk$，成功概率为 $p^*$：

\[
\operatorname{Var}(C_t \mid n, R_t) = \frac{nk(1 - p^*)}{(p^*)^2} = nk \cdot \frac{\frac{\rho R_t}{k + \rho R_t}}{\left(\frac{k}{k + \rho R_t}\right)^2} = nk \cdot \frac{\rho R_t}{k + \rho R_t} \cdot \frac{(k + \rho R_t)^2}{k^2}
\]
分子分母对消 $k(k + \rho R_t)$：

\[
= \frac{n \rho R_t (k + \rho R_t)}{k} = \frac{nk \rho R_t + n \rho^2 R_t^2}{k} = \rho n R_t + \frac{(\rho R_t)^2 n}{k}
\]
清晰展示了泊松方差 $\rho n R_t$ 与个体超传播方差 $\frac{(\rho R_t)^2 n}{k}$ 的代数叠加！


\subsubsection{3.2.3 对数似然与得分函数求解}
\[
\ln L(R_t) = \text{const} - (nk + C_t) \ln(k + \rho R_t) + C_t \ln R_t
\]
对 $R_t$ 求偏导：

\[
S(R_t) = \frac{\partial \ln L}{\partial R_t} = -\frac{\rho(nk + C_t)}{k + \rho R_t} + \frac{C_t}{R_t} = \frac{-\rho R_t(nk + C_t) + C_t(k + \rho R_t)}{R_t(k + \rho R_t)} = \frac{k(C_t - \rho n R_t)}{R_t(k + \rho R_t)}
\]
令 $S(R_t) = 0$，解得唯一极大似然估计量 $\widehat{R}_t^{\text{MLE}} = \frac{C_t}{\rho n}$。


\subsubsection{3.2.4 无偏性验证（双层全期望展开）}
利用双层全期望公式：

\[
\mathbb{E}[\widehat{R}_t \mid n, R_t] = \frac{1}{\rho n} \mathbb{E}[C_t \mid n, R_t] = \frac{1}{\rho n} \mathbb{E}_{I_t}\Big( \mathbb{E}_{C_t}[C_t \mid I_t] \;\Big|\; n, R_t \Big)
\]
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 内层：二项报告抽样均值 $\mathbb{E}[C_t \mid I_t] = \rho I_t$；
\item 外层：独立分支和均值 $\mathbb{E}[I_t \mid n, R_t] = \mathbb{E}\left[\sum_{i=1}^n X_{i,t}\right] = n R_t$；
\end{itemize}
代入：

\[
\mathbb{E}[\widehat{R}_t \mid n, R_t] = \frac{1}{\rho n} \cdot \rho (n R_t) = R_t \quad (\text{严格无偏！})
\]

\subsubsection{3.2.5 Fisher 信息量与 Cramér–Rao 下界确立}
\[
\mathcal{I}(R_t \mid n) = \operatorname{Var}(S(R_t)) = \frac{k^2 \operatorname{Var}(C_t)}{R_t^2(k + \rho R_t)^2} = \frac{k^2 \cdot \frac{n \rho R_t (k + \rho R_t)}{k}}{R_t^2(k + \rho R_t)^2} = \frac{k \rho n}{R_t(k + \rho R_t)} = \frac{n}{\frac{R_t}{\rho} + \frac{R_t^2}{k}}
\]

\textbf{【回填 4 · 正文式 (5)】}
\end{quote}
\begin{quote}\small\color{black!75}
\begin{equation*}
\mathcal{I}(R_t \mid n) = \frac{n}{\frac{R_t}{\rho} + \frac{R_t^2}{k}} \tag{eq:fisher\_info}
\end{equation*}
\end{quote}

取倒数得下界：

\[
\mathcal{I}^{-1} = \frac{R_t}{\rho n} + \frac{R_t^2}{kn} \equiv \operatorname{Var}(\widehat{R}_t \mid n, R_t)
\]

\begin{quote}\small\color{black!75}

\end{quote}

无偏估计量方差达到 Cramér–Rao 下界，确立其为 UMVUE！

\lim_{\rho \to 1} V(n, \rho) = v_R + \frac{\bar{R}}{n} + \frac{\bar{R}^2 + v_R}{k n} > v_R \tag{eq:rho\_limit}
\end{equation*}
\end{quote}

\textbf{极限二：人群基数极限 $n \to \infty$}

\[
\lim_{n \to \infty} V(n, \rho) = v_R + \lim_{n \to \infty} \frac{1}{n} \left[ \frac{\bar{R}}{\rho} + \frac{\bar{R}^2 + v_R}{k} \right] = v_R + 0 = v_R
\]

\textbf{政策启示}：完全消除漏报只能干掉第一项漏报抽稀噪声；人群内部固有的泊松相遇离散度 $\bar{R}/n$ 与超级传播重尾离散 $\frac{\bar{R}^2+v_R}{kn}$ 永远无法被 $\rho$ 消除。唯有扩大监测的地理与人群基数 $n \to \infty$，大数定律才能统摄消除全部微观噪声。

\subsection{3.5 命题 4 与推论 1：多期时间抽样、AR(1) 求和与 Cochran 对偶}

\subsubsection{3.5.1 独立环境下的预算恒常性}
在总人数预算 $B = T \cdot m$ 约束下，跨期均值估计量的方差分解为：

\[
\operatorname{Var}(\overline{\widehat{R}}_T) = \frac{1}{T^2}\operatorname{Var}\left(\sum_{t=1}^T R_t\right) + \frac{1}{T^2}\sum_{t=1}^T \operatorname{Var}(\widehat{R}_t \mid R_t)
\]
代入单期条件抽样方差 $\frac{A}{m}$：

\[
\text{抽样项} = \frac{1}{T^2} \cdot T \frac{A}{m} = \frac{A}{Tm} = \frac{A}{B} \quad (\text{恒为常数！})
\]

\begin{quote}\small\color{black!75}
\textbf{【回填 12 · 正文式 (12)】}
\end{quote}
\begin{quote}\small\color{black!75}
\begin{equation*}
\operatorname{Var}(\overline{\widehat{R}}_T \mid n_T) = \frac{v_R}{T} + \frac{A}{B} \tag{eq:var\_budget\_indep}
\end{equation*}
\end{quote}

\textbf{惊人结论}：在固定总样本预算下，无论怎么分配 $T$ 与 $m$，抽样误差项永远是常数 $A/B$！要想降低总方差，\textbf{唯一的方法是拉长观测期数 $T$ 去平滑宏观不可约环境变异 $v_R$}。


\subsubsection{3.5.2 AR(1) 环境自相关的双重级数求和（错位相减法逐行展开）}
在 AR(1) 自相关下，环境方差项展开为：

\[
\operatorname{Var}\left(\sum_{t=1}^T R_t\right) = T v_R + 2 v_R \sum_{s=1}^{T-1} (T-s) r^s
\]
定义等差乘等比级数：

\[
S \triangleq \sum_{s=1}^{T-1} (T-s) r^s = (T-1)r + (T-2)r^2 + \dots + 1 \cdot r^{T-1}
\]
两端同乘公比 $r$：

\[
r S = (T-1)r^2 + (T-2)r^3 + \dots + 1 \cdot r^T
\]
两式相减：

\[
(1-r)S = (T-1)r - \left[ r^2 + r^3 + \dots + r^{T-1} \right] - r^T = T r - \sum_{s=1}^T r^s = T r - \frac{r(1 - r^T)}{1 - r}
\]
两端除以 $(1-r)$：

\[
S = \frac{T r}{1 - r} - \frac{r(1 - r^T)}{(1 - r)^2}
\]
代回环境总方差：

\[
\operatorname{Var}\left(\sum_{t=1}^T R_t\right) = T v_R + 2 v_R S = T v_R + 2 v_R \left[ \frac{T r}{1 - r} - \frac{r(1 - r^T)}{(1 - r)^2} \right] = v_R T \left[ 1 + \frac{2r}{1-r} - \frac{2r(1 - r^T)}{T(1-r)^2} \right]
\]
通分化简括号内前两项：$1 + \frac{2r}{1-r} = \frac{1-r+2r}{1-r} = \frac{1+r}{1-r}$：

\[
\operatorname{Var}\left(\sum_{t=1}^T R_t\right) = v_R T \left[ \frac{1+r}{1-r} - \frac{2r(1 - r^T)}{T(1-r)^2} \right]
\]
两端除以 $T^2$，得附录 A.4 精确双重级数求和闭式。当 $T \gg \frac{1}{1-r}$ 时，精确式良好近似为有效独立期数折减形式：


\begin{quote}\small\color{black!75}
\textbf{【回填 13 · 正文式 (13)：有效独立期数近似式】}
\end{quote}
\begin{quote}\small\color{black!75}
\begin{equation*}
\operatorname{Var}(\overline{\widehat{R}}_T \mid n_T) \approx \frac{v_R}{T_{\operatorname{eff}}(T, r)} + \frac{A}{B}, \qquad T_{\operatorname{eff}}(T, r) \triangleq T \frac{1-r}{1+r} \tag{eq:var\_budget\_ar1}
\end{equation*}
\end{quote}

\subsubsection{3.5.3 离散可行设计集合}
当要求各期风险集相同且为正整数，并精确用尽总预算 $B$ 时：


\begin{quote}\small\color{black!75}
\textbf{【回填 14 · 正文式 (14)】}
\end{quote}
\begin{quote}\small\color{black!75}
\begin{equation*}
\mathcal{T}(B, \rho) \triangleq \left\{ T \in \mathbb{N}_+ \;:\; \frac{B}{\rho T} \in \mathbb{N}_+ \right\} \tag{eq:feasible\_T}
\end{equation*}
\end{quote}

\subsubsection{3.5.4 推论 1：成本约束下的最优单期规模与 Cochran 对偶}
在总经费预算 $\mathcal{B} = T(c_0 + c_1 m)$ 约束下，代入 $T = \frac{\mathcal{B}}{c_0 + c_1 m}$，目标方差函数关于 $m$ 严格凸。唯一内部最优单期规模直接给出：


\begin{quote}\small\color{black!75}
\textbf{【回填 15 · 正文式 (15)】}
\end{quote}
\begin{quote}\small\color{black!75}
\begin{equation*}
m^* = \sqrt{\frac{c_0}{c_1} \cdot \frac{A}{v_R}} = \sqrt{\frac{c_0}{c_1} m_\times} \tag{eq:optimal\_scale}
\end{equation*}
\end{quote}

\textbf{Cochran (1977) 抽样对偶}：推论 1 中的方差与总成本结构，在数学形式上同构于经典两阶段抽样（Two-stage Sampling）的费用分配模型：时间观测期数 $T$ 对应初级抽样单元数，单期期望捕获规模 $m$ 对应次级样本量。二阶导数 $\frac{2c_0 A}{\mathcal{B} m^3} > 0$ 严格保证了最优解的全局唯一性。

\subsection{3.6 命题 5：增长判定的单调似然比（MLR）一阶差分与离散功效}

\subsubsection{3.6.1 MLR 一阶差分严格为正证明}
单侧假设检验：

\[
H_0: R_t \le 1 \quad \text{vs} \quad H_1: R_t > 1
\]

\begin{quote}\small\color{black!75}
\textbf{【回填 18 · 正文式 (18)】}
\end{quote}
\begin{quote}\small\color{black!75}
\begin{equation*}
H_0: R_t \le 1 \qquad \text{对} \qquad H_1: R_t > 1 \tag{eq:hypo\_growth}
\end{equation*}
\end{quote}

对任意备择强度 $R_1 > R_0$，似然比对数形式为：

\[
\ln \frac{\Pr_{R_1}(C_t = j)}{\Pr_{R_0}(C_t = j)} = nk \ln \frac{p^*(R_1)}{p^*(R_0)} + j \ln \frac{1 - p^*(R_1)}{1 - p^*(R_0)}
\]
计算对计数值 $j$ 的一阶差分：

\[
\Delta(j) \triangleq \ln \frac{\Pr_{R_1}(j+1)}{\Pr_{R_0}(j+1)} - \ln \frac{\Pr_{R_1}(j)}{\Pr_{R_0}(j)} = \ln \frac{1 - p^*(R_1)}{1 - p^*(R_0)}
\]
代入 $1 - p^*(R) = \frac{\rho R}{k + \rho R}$：

\[
\frac{1 - p^*(R_1)}{1 - p^*(R_0)} = \frac{\frac{\rho R_1}{k + \rho R_1}}{\frac{\rho R_0}{k + \rho R_0}} = \frac{R_1(k + \rho R_0)}{R_0(k + \rho R_1)} = \frac{k R_1 + \rho R_0 R_1}{k R_0 + \rho R_0 R_1}
\]
由于 $R_1 > R_0$，分子 $k R_1 + \rho R_0 R_1 > k R_0 + \rho R_0 R_1$ 分母，该比值严格大于 1！

取自然对数后，一阶差分 $\Delta(j) > 0$ 恒成立！

证明了似然比关于充分统计量 $C_t$ \textbf{严格单调递增}，Karlin–Rubin 定理严格适用！


\subsubsection{3.6.2 离散临界值与精确功效}
临界值由使边界处超额拒绝概率受控的最小整数唯一确定：


\begin{quote}\small\color{black!75}
\textbf{【回填 19 · 正文式 (19)】}
\end{quote}
\begin{quote}\small\color{black!75}
\begin{equation*}
c_\alpha = \min \left\{ c \in \mathbb{N} \;:\; \Pr_{R_t = 1}(C_t \ge c) \le \alpha \right\} \tag{eq:crit\_val}
\end{equation*}
\end{quote}

\begin{quote}\small\color{black!75}
\textbf{【回填 20 · 正文式 (20)】}
\end{quote}
\begin{quote}\small\color{black!75}
\begin{equation*}
\pi(n, \delta) \triangleq \Pr_{R_t = 1 + \delta}(C_t \ge c_\alpha) = 1 - F_{\operatorname{NB}}\!\left(c_\alpha - 1; \; nk, \; \frac{k}{k + \rho(1+\delta)}\right) \tag{eq:power\_exact}
\end{equation*}
\end{quote}

\subsubsection{3.6.3 离散功效锯齿波（Sawtooth Wave）成因}
因为观测计数 $C_t$ 只能取整数，临界值 $c_\alpha(n)$ 随样本量 $n$ 呈阶梯状跳变：

\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 当 $n$ 在某个区间微增时，临界值 $c_\alpha$ 保持不变，由于样本量变大，功效连续上升；
\item 一旦 $n$ 跨过某个临界点，为了控制显著性水平 $\alpha$，$c_\alpha$ 突然跳跃到 $c_\alpha + 1$，拒绝门槛突然拔高，导致统计功效瞬间出现向下跳跃！
\item 这解释了图 2 模拟中为什么连续增加病例数，功效曲线会出现特有的锯齿波动，证实了离散枚举求解最小样本量的必要性。
\end{itemize}

\end{quote}

\subsection{5.2 为什么必须用 FGLS（可行广义最小二乘法）？}
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 普通 OLS 假定误差项具有同方差；
\item 但实测发现：残差具有极端厚尾（偏度高达 8.63），且小规模组的方差--均值比高达 5.32，大规模组收缩至 0.99，存在剧烈的反比非齐次方差；
\item 必须采用以拟合值平方倒数 $1/\hat{\mu}^2$ 加权的 FGLS，并配合 1,500 次按州聚类的 Bootstrap 估计标准误。
\end{itemize}

\subsection{5.3 核心实证估计结果}
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 规模斜率项 $\hat{b} = 2.2434$（95\% CI $[1.50, 3.02]$），\textbf{1,500 次 Bootstrap 重抽无一次小于等于零（$p < 10^{-4}$）}，强力证实了 $b/D_t$ 递减项的真实存在；
\item 经验拟合截距 $\hat{a} = 0.0991$；经验平衡点 $m_\times^{\mathrm{emp}} = \hat{b}/\hat{a} \approx 22.6$ 例/周；
\item \textbf{误差份额分解}：在流行初期平均 0.181 的总误差中，规模相关项占 45.1\%，不可约经验下限占 54.6\%（四至五成半）。
\end{itemize}

\subsection{5.4 达峰期震撼反转：88.9\% 偏差 vs 15.5\% 集成预测}
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item \textbf{表象与传统误读}：在达峰期，各规模组的总相对误差恒定在 0.292–0.312，看起来不管怎么增大病例规模，误差完全不下降。很多人据此宣称“达峰期病例数失效了”。
\item \textbf{论文的数学正交分解}：
\end{itemize}
\[
\text{总误差} = \underbrace{\left(\frac{\bar{R}_{\mathrm{peak}} - \bar{R}_{\mathrm{early}}}{\bar{R}_{\mathrm{early}}}\right)^2}_{\text{常数基准偏移项（占 88.9\%）}} + \underbrace{\text{条件方差项（占 11.1\%）}}_{\text{规模效应仍显著为正！}}
\]
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]
\item 达峰期看似恒定的高误差，\textbf{整整 88.9\% 是因为疫情达峰转向、历史平稳基准失灵导致的常数漂移}！
\item 剥离常数漂移后，达峰期内部的纯条件方差依然显著随规模递减（$\hat{b} = 7.9272$）；
\item \textbf{外部验证的终极呼应}：
\end{itemize}
在引入 CDC FluSight 官方真实多模型前瞻集成预测后，\textbf{达峰期的均值偏差占比从静态单模型的 88.9\% 骤降至 15.5\%}！

直接在实证上回答了：跨过规模平衡点后，单纯扩充样本量已经边际递减，必须依靠多模型自适应集成来消除均值漂移。


\subsection{5.5 欧洲 11 国 COVID-19 跨病种验证}
\begin{itemize}[leftmargin=2em, itemsep=2pt, parsep=0pt]

\item 证明了规模递减规律跨病种、跨地域的高度稳健性，同时证实特征平衡点随时间分辨率和监测尺度变动。
\end{itemize}

\section{第六部分：硕士中期答辩高频质询 Q\&A 宝典（11 问 11 答）}

\subsubsection{Q1: 你的研究与现有的 EpiEstim (Cori) 和 Parag 的信息论下界有什么本质区别？}
\begin{quote}\small\color{black!75}
\textbf{答}：Cori 等人的 EpiEstim 解决的是“如何在滑动窗口下估计时变再生数”，Parag 等人的研究确立了“以当期瞬态参数 $R_t$ 为目标时信息量随病例数线性增长”的物理极限。
\end{quote}
\begin{quote}\small\color{black!75}
本文的本质区别在于\textbf{推断目标的切换}：我们证明，一旦将推断目标由当期瞬态参数 $R_t$ 切换为跨期基础水平 $\bar{R}$，由于单期横截面样本无法消除全员共享的外生宏观环境扰动，方差标度律发生根本改变，出现不可约环境方差下限 $v_R$ 与特征规模平衡点 $m_\times$。本文填补的是从“单期推断”跨越到“监测资源运筹设计”的理论空白。
\end{quote}

\subsubsection{Q2: 为什么一定要用负二项分支过程？用经典的泊松过程不行吗？}
\begin{quote}\small\color{black!75}
\textbf{答}：传染病学中普遍存在极强的超传播现象（Lloyd-Smith 等 2005），约 20\% 的感染者引发 80\% 的传播。
\end{quote}
\begin{quote}\small\color{black!75}
泊松分布强加了方差等于均值（$k \to \infty$），这在数学上会严重低估小计数阶段的重尾抽样风险，人为低估达到指定功效所需的样本量需求（如图 2 所示，强超传播下样本量需求暴增 3 倍）。引入负二项分布不仅具有流行病学真实性，更在数理上通过 PGF 复合运算保证了二项抽样下的分布族封闭性，为全方差分解提供了优雅的解析基准。
\end{quote}

\subsubsection{Q3: 理论上的 $m_\times = A/v_R$ 与实证拟合得到的 $b/a \approx 22.6$ 能否直接画等号？}
\begin{quote}\small\color{black!75}
\textbf{答}：不能直接等同，实证比值是理论平衡点的\textbf{经验映射物与量级参照}。
\end{quote}
\begin{quote}\small\color{black!75}
理论上的 $m_\times$ 是在单代已知参数下的解析临界点；而实证中的 $a = 0.0991$ 与 $b = 2.2434$ 是在真实流感周度时间序列中对 $D_t$ 进行仿射拟合的参数，其中 $a$ 既包含了宏观环境波动，也吸收了滞后卷积平滑失配的常数偏差。实证的核心价值在于\textbf{验证了理论预测的仿射递减与平台收敛形状}，而非点位精确物理测量。
\end{quote}

\subsubsection{Q4: 你在局限性里提到 $v_R$ 始终是拟合量而非测量量，如果让你来测，在实务中怎么才能把它测出来？}
\begin{quote}\small\color{black!75}
\textbf{答}：正如我们在第 6.2 节方法学展望中所提出的，未来可以通过\textbf{“双轨监测体系”}实现纯外生环境方差 $v_R$ 的解耦测度：
\end{quote}
\begin{quote}\small\color{black!75}
目前的医院住院监测混合了就医行为与填报时滞；如果能在代表性社区布设固定人群的前瞻性主动追踪队列（如定期家庭采样），直接测得无就医行为干扰的真实社区传播强度，就能将外生宏观环境方差 $v_R$ 与监测系统的代理平滑偏差完全分离识别。
\end{quote}

\subsubsection{Q5: 为什么推论 1 里的最优单期规模公式会和 Cochran 的两阶段抽样同构？}
\begin{quote}\small\color{black!75}
\textbf{答}：这体现了数理统计深层的对偶之美。
\end{quote}
\begin{quote}\small\color{black!75}
在时间序列监测中，期数 $T$ 本质上就是初级抽样单元（PSU），单期捕获病例数 $m$ 就是次级抽样单元（SSU）。固定维持成本 $c_0$ 发生于每一期，边际采集成本 $c_1$ 发生于每个病例。这与 Cochran (1977) 调查抽样中“在有限预算下权衡抽取多少个群（群成本 $c_0$）与每群调查多少人（人均成本 $c_1$）”的数学优化模型完全同构，二阶导数 $\frac{2c_0 A}{\mathcal{B} m^3} > 0$ 严格保证了最优解的全局唯一性。
\end{quote}

\subsubsection{Q6: 实证中为什么用 FGLS 而不用我们最熟悉的普通最小二乘法 (OLS)？}
\begin{quote}\small\color{black!75}
\textbf{答}：因为真实监测数据的残差具有极强的异方差与厚尾性。
\end{quote}
\begin{quote}\small\color{black!75}
流感住院损失的偏度高达 8.63，小规模段的方差--均值比高达 5.32，大规模段收缩至 0.99，表现出剧烈的反比非齐次方差。如果使用普通 OLS，小样本段的极大极端值会过度主导回归线，估计功效损失极大；FGLS 通过一阶拟合残差平方倒数进行迭代加权，在大样本下达到最优线性无偏估计（BLUE）。
\end{quote}

\subsubsection{Q7: 达峰期看似误差恒定在 0.3 左右，你凭什么说病例规模在达峰期依然有用？}
\begin{quote}\small\color{black!75}
\textbf{答}：凭严格的\textbf{均值--方差正交代数分解}。
\end{quote}
\begin{quote}\small\color{black!75}
我们证明了达峰期看似恒定的高误差中，整整 88.9\% 来源于疫情转折导致的常数基准漂移 $(\bar{R}_{\mathrm{peak}} - \bar{R}_{\mathrm{early}})^2 / \bar{R}_{\mathrm{early}}^2 = 0.2669$。真正反映推断波动的纯条件方差只占 11.1\%。当我们使用达峰期自身均值剥离常数漂移后，规模相关项系数 $\hat{b} = 7.9272$ 依然高度显著为正。失效的是跨期平稳性假设，而不是病例规模本身。
\end{quote}

\subsubsection{Q8: 滞后暴露权重取 $w = (0.65, 0.25, 0.10)$ 的依据是什么？换一组权重结论还成立吗？}
\begin{quote}\small\color{black!75}
\textbf{答}：有两个依据：第一，加权平均回溯时间为 $1.45$ 周（约 $10.2$ 天），与流感临床从感染、潜伏（1–2天）、发病就诊（3–5天）到填报确认的复合特征时滞（约 10 天）完全吻合；
\end{quote}
\begin{quote}\small\color{black!75}
第二，正文第 5.1 节进行了严格的权重敏感性检验：无论换用单周滞后（7天）还是三周等权（14天），规模斜率 $b$ 始终在 $1.9$ 到 $3.1$ 之间，聚类 Bootstrap 置信区间严格远离零点，1,500 次重抽无一次小于零，核心科学结论对权重设定高度稳健。
\end{quote}

\subsubsection{Q9: 为什么命题 3 说提高报告率 $\rho$ 存在无法消除的方差下界？现实中疾控提高检测率没有意义吗？}
\begin{quote}\small\color{black!75}
\textbf{答}：提高报告率具有显著价值，但它的作用机制具有局限性。
\end{quote}
\begin{quote}\small\color{black!75}
全方差公式严格表明：提高报告率 $\rho \to 1$ 只能消除由于漏报产生的纯二项抽样方差 $\frac{(1-\rho)\bar{R}}{\rho n}$，但它无法消除人群中固有的微观计数随机性 $\frac{\bar{R}}{n}$，更无法消除个体超级传播引发的子代抽样方差 $\frac{\bar{R}^2+v_R}{kn}$。唯有扩大地理或人群基数 $n$，通过大数定律才能同时压低所有微观随机性。
\end{quote}

\subsubsection{Q10: 这篇论文对国家公共卫生监测体系的建设，到底能提供什么实际建议？}
\begin{quote}\small\color{black!75}
\textbf{答}：给出了两阶段“差异化资源配置”判据：
\end{quote}
\begin{quote}\small\color{black!75}
1. \textbf{在疫情初期与低发期（$m < m_\times$）}：系统处于微观噪声主导区，此时应集中资源扩建哨点、扩大病例捕获，能够迅速跨过平衡点，获得显著的方差收益；
\end{quote}
\begin{quote}\small\color{black!75}
2. \textbf{在疫情高峰期与常态化监测期（$m > m_\times$）}：系统跨过特征平衡点进入饱和区，此时继续单纯追求捕获更多病例已边际收益递减，监测资源应当果断由“扩量”转向“提质”——即转向引入多模型前瞻集成预测，并补充气象、人群流动等外部环境协变量以解释不可约环境方差。
\end{quote}
