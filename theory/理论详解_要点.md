# 《疫情监测中的病例规模收益边界》理论详解要点

本文是 PDF 讲义《小论文理论详解与建议》的速查版。完整推导、图表、核验细节与参考文献见同目录的 理论详解.pdf。文中的“原文第 N 行”指论文 LaTeX 源码 main.tex 的行号，“原文式 N”指论文 PDF 中的公式编号。

## 一、论文要回答的问题

论文的核心问题是：个体超传播、不完全报告和共同环境扰动同时存在时，多报告一些病例能换来多少推断精度。答案取决于估计目标。

- 目标 A 是当期传播参数 R_t。测量方差随期望报告规模 m = ρn 单调趋于零。
- 目标 B 是跨期基础水平 R̄。单期估计留有一个不随规模下降的环境方差 v_R。

规模项与环境项相等时的期望报告规模 m× = A / v_R 把“规模何时不再主导误差”变成了一个可计算的设计量。

## 二、模型与关键公式

| 层次 | 原式 | 含义 |
|---|---|---|
| 个体传播(原文式 1) | E[X_{i,t} ∣ R_t] = R_t,Var(X_{i,t} ∣ R_t) = R_t + R_t²/k | 负二项分支;k 越小超传播越强 |
| 报告(原文式 2) | C_t ∣ I_t ~ Binomial(I_t, ρ) | 每个感染独立地以概率 ρ 被报告 |
| 环境(原文式 3) | E[R_t ∣ n] = R̄,Var(R_t ∣ n) = v_R > 0 | 同一期所有感染者共享同一个 R_t |

由这三层可以推出以下结论。

1. 命题 1(原文式 4–6):C_t ∣ n, R_t ~ NB(nk, p*),其中 p* = k/(k + ρR_t)。估计量 C_t/(ρn) 是 R_t 的最大似然估计,在每个有限 n 上精确达到 Cramér–Rao 下界:Var(C_t/(ρn)) = R_t/(ρn) + R_t²/(kn)。
2. 命题 2(原文式 7–8):由全方差公式和 E[R_t²] = R̄² + v_R,得 Var(C_t/(ρn)) = v_R + A/m,其中 A = R̄ + ρ(R̄² + v_R)/k。
3. 定义 1(原文式 9):m× = A/v_R。规模翻倍带来的方差降幅为 1/[2(1 + m/m×)],在 m = m× 处恰为 25%。
4. 命题 3(原文式 10–13):提高 ρ 只能消除漏报带来的抽样方差;扩大 n 能让全部规模项同时衰减。
5. 命题 4 与推论 1(原文式 14–18):给定每期固定成本 c_0 与单例成本 c_1,最优单期规模为 m* = √((c_0/c_1)·m×)。
6. 命题 5(原文式 19–22):对预测方差做全方差分解。只有报告序列可见时,感染压力 Λ 本身的不确定性会额外贡献一项。
7. 命题 6(原文式 23–25):在 NB 下对 H_0: R_t ≤ 1 做精确的离散单侧检验。检验水平不超过 α,功效随 n 呈锯齿状变化。

## 三、需要记住的数值

以论文图 1 的参数计算(R̄ = 1.15,v_R = 0.04,k = 0.35,ρ = 0.25):

- A = 2.1232,m× = 53.08 例/期;
- 规模翻倍的方差降幅:m = 10 时 42.1%,m = m× 时 25.0%,m = 200 时 10.5%;
- 推论 1:c_0/c_1 = 10 时 m* = 23.0,c_0/c_1 = 100 时 m* = 72.9;
- 整数预算例(c_0 = 100,c_1 = 1,预算 600):T = 1 到 5 的方差依次为 0.04425、0.02531、0.02041、0.02062、0.02923,整数最优为 T = 3、m = 100,而连续松弛给出 m* = 72.86;
- AR(1) 下 T_eff ≈ T(1 − r)/(1 + r) 恒高估环境项:r = 0.8 时,T = 26 高估 20.5%,T = 10 高估 65.8%;
- 命题 6(k = 0.35,δ = 0.30):功效首次达到 0.8 的样本量为 568,此后恒不低于 0.8 的稳定样本量为 581。

实证部分(全美 CDC NHSN 流感住院,16,218 个州周观测):

- 流行初期 FGLS 拟合 a = 0.0991,b = 2.2434;
- 经验交叉点 b/a = 22.6 例/周,区间 [13.7, 33.7];
- 39%–55% 的误差份额落在截距上;
- 达峰期常数均值偏移占总误差的 88.9%;
- FluSight 集成把达峰期均值偏差占比压缩到 15.5%。

## 五、答辩准备

最可能被追问的四个问题如下。

1. 目标 A 与目标 B 的区别。前者的环境波动就是待测对象;后者的同一波动是单期无法消除的误差。
2. v_R 能否从数据中识别。不能单独识别,因为截距 a 混入了口径差等与规模无关的误差。
3. 截距、斜率与理论参数的关系。两者都高于情景隐含值,分别受 G 与世代 R 的口径差、随机分母的二项噪声影响。
4. 离散检验的水平与功效。水平不超过 α;若要求水平恰好为 α,可用随机化检验(Karlin–Rubin);功效应报告稳定样本量。

白板上最少要能在五分钟内推完一条主线:负二项抽稀 → 命题 1 的 Fisher 信息 → 命题 2 的 v_R + A/m → m× 与翻倍降幅公式。
